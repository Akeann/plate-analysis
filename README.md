# plate-analysis

Обработка данных 96-луночного планшета (MTT-тест на цитотоксичность): расчёт жизнеспособности клеток, оценка IC50, сравнение двух серий веществ, построение кривых доза-эффект и текстовый отчёт.

## Назначение

На вход подаются сырые показания планшетного ридера (оптическая плотность при 570 нм). Программа нормирует их на бланк и контроль, переводит в проценты жизнеспособности, оценивает IC50 линейной интерполяцией по логарифму концентрации, сравнивает серии A–D и E–H по критерию Стьюдента, строит кривые доза-эффект и записывает отчёт в каталог `results/`.

## Входные данные

Файл `data/raw/plate_2024_03_14.csv`, кодировка UTF-8, разделитель «;».

Первые три строки — заголовок эксперимента, четвёртая — номера колонок, далее восемь строк данных.

Раскладка планшета: колонка 1 — бланк, колонка 2 — контроль, колонки 3–12 — десять концентраций (двукратное разведение от 100 мкМ), строки A–H — восемь веществ.

## Запуск

```bash
python src/main.py
```

## Ограничения и известные проблемы

В соответствии с правилом пяти правок, на данном этапе были исправлены только критические дефекты. Остальные проблемы зафиксированы здесь как технический долг:

1. **IC50 = -1:** означает, что кривая не пересекает уровень 50 % в диапазоне измеренных концентраций (в файле-примере — вещество G). Значение попадает в отчёт без пометки. Ошибка в отсутствии проверки результата.
2. **Подавление ошибок парсинга:** в функции `read_plate()` используется `except: pass`. Если ячейка содержит нечитаемое число (битые данные), она молча пропускается, и расчеты могут быть неверными.
3. **Магические константы:** раскладка планшета (12 колонок, 100.0 мкМ, деление на 4) жестко зашита в код.
4. **Дублирование кода:** блоки обработки серий A и B дублируются.
5. **Неинформативные имена переменных:** `d`, `i`, `p`, `q`, `z`, `xx`, `cc`.
6. **Отсутствие контекстных менеджеров:** файлы открываются через `open()`, а не `with open()`.
7. **Мертвый код:** закомментированные импорты `seaborn` и `pandas`, закомментированный блок вывода проверки.
8. **Критерий Стьюдента:** сравнение серий выполняется по 4 точкам, перенесено из исходного скрипта без изменений (обсуждается).
9. **Отсутствие тестов:** автоматические тесты отсутствуют.
